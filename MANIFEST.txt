🏗️ ARCHITECTURE:

  Three-layer design:
  
  ┌─────────────────────────────────────┐
  │  VIEWS (presentation)               │  ← User sees/edits here
  │  • Program 1-4                      │
  │  • Schedule (aggregated)            │
  │  • Overview (dashboard)             │
  │  • Credits (auto-generated)         │
  └─────────────────────────────────────┘
                ↕️ QUERY formulas
  ┌─────────────────────────────────────┐
  │  APPS SCRIPT (logic)                │  ← Orchestration layer
  │  • onEdit triggers                  │
  │  • Custom menus                     │
  │  • CRUD operations                  │
  │  • Data validation                  │
  └─────────────────────────────────────┘
                ↕️ Write operations
  ┌─────────────────────────────────────┐
  │  DATABASE (data)                    │  ← Single source of truth
  │  • _DB_Posts (master registry)     │
  │  • _DB_Personer (people)           │
  │  • _DB_Program (metadata)          │
  │  • _DB_PostTyper (templates)       │
  │  • _DB_Logg (timecode)             │
  │  • _DB_Settings (config)           │
  └─────────────────────────────────────┘
